Analysis Code for "Neoadjuvant PD1 plus CTLA-4 immune checkpoint blockade in surgically resectable recurrent glioblastoma: a randomized surgical window-of-opportunity trial" (Sun et al., Nature Communications, 2026)

Timepoint trajectory analysis each patient's PBMC RNA-seq profile across multiple timepoints: TimepointTrajectorAnalysis.R
TCR-seq Analysis Code: LymphoSeqForTCRb.R

Notes

The raw and mapped RNA-seq data has been deposited to Gene Expression Omnibus (GEO) under accession number GSE318645.

The processed TCR-seq data has been deposited to Zenodo: https://doi.org/10.5281/zenodo.21725791

Requirements: R (tested with version 4.2.2).
